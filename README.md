# KHIPU — Receipt Chain Hologram (prototype v0.1)

A khipu (quipu) is a physical data structure: knots on cords as records. This
prototype renders the estate's real training receipts (SZLHOLDINGS/
frontier-54-runs, mesh/ - public dataset) as pendant cords from a main spine.

- Each cord is one receipt, ordered by observed timestamp.
- Knots encode the receipt digest (big knots = byte-pair >= 0x50, long knots
  = byte-pair mod 7 == 0); the cord's sway and length also derive from it.
- Drag to rotate, scroll to zoom, click a cord to open its receipt panel.
- The panel shows the declared receipt_sha256 and re-hashes the displayed
  bytes locally with Web Crypto. When the local hash differs it says so
  honestly: the worker computes its digest over its canonical in-memory
  form, not Hub file bytes - the declared digest remains the source of truth
  (fail-closed; no fabricated match).

Built as a single self-contained HTML file with an inline 3D engine. The
production version (Spark / SPZ + scan-to-3D assets) is the next step on the
holographic frontier lane.

Honesty: knots and layout derive only from the digests shown; nothing here
is a measured training metric. Energy on the training lanes is carried by
the worker receipts themselves (MEASURED NVML / zeus window when available,
UNAVAILABLE otherwise - never fabricated).
